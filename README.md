# Shailesh Shrestha — Portfolio

Personal portfolio site: [shailesh-stha.github.io/Shailesh](https://shailesh-stha.github.io/Shailesh/)

Static single-page site — no build step, no dependencies. Sections: intro,
skills, experience, certifications, featured projects, and a blog (in
progress).

## Stack

Vanilla HTML, CSS, and JavaScript. Hosted on GitHub Pages.

## Local development

No build step — just open `index.html` in a browser, or serve the folder
with any static server, e.g.:

```
npx serve .
```

## Structure

```
index.html   Page markup
index.css    Styles (CSS custom properties for light/dark theming)
index.js     Interactivity (nav, theme switcher, section animations)
assets/      Images and icons
```
